# Recording checklist

Tick each before you press record. Ten items, about four minutes.

1. Preflight says GO: `node scripts/demo-preflight.mjs --base <your deployment>`. Read any warning aloud to yourself and decide if the take can live with it.
2. You have read the sample notes once (Peek at the page in level 1). You cannot catch a bluff you do not recognise.
3. Headphones on and plugged in before the browser opens. The examiner's voice must not reach the microphone, or your interruption is muddied by echo.
4. Quiet room, door shut, phone on silent and face down.
5. Notifications off: Windows Focus assist on, Slack, mail and chat closed, no pop-ups at the corner of the screen.
6. One browser window in a private window, bookmarks bar hidden, only the Aloud tab open. A private window means the run starts fresh: 0 XP, no streak.
7. Browser zoom 110 percent. Window at 1920 by 1080 or the largest size the recorder captures at 30 frames per second.
8. Microphone chosen in the browser and in the operating system, input level peaking around the middle of the meter at conversation volume. Allow the microphone in the address bar before the take, not during it.
9. Screen recorder set to 1080p, 30 fps, system audio and microphone on separate tracks if it allows, cursor visible, output to a local folder with room for 1 GB.
10. Dry run of the first 45 seconds: front page, Start the sample run, one Say it answer. Then close the private window and open a new one so the take starts clean. Script open on a second screen or printed, `docs/demo/SCRIPT.md`, with the interruption line marked. Water within reach.
